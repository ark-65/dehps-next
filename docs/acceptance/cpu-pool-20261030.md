## 实际基准

完整数据见cpu-pool-benchmark-20261030.json。使用Next3521期历史，三种实际FFT/Newton/ridge配方，固定15个不同合法起点，多次重复用于测速度。长块各450次真实拟合、12600个梯度步骤，预热不计入计时；不是450个独立新开奖样本。

独立进程相反顺序两次复测的合并吞吐：4线程15.21拟合/秒、6线程13.52、8线程16.83，因此预测训练保持8。筛选亦包含2/12/16。16线程第一个长块62.20秒、7.23拟合/秒；第二块超过120秒后人工终止，取消记录保留，不计为完成。

固定真实Qwen研究请求，4/6/8/12线程一对请求分别64.71/57.64/55.83/41.40秒；8和12分别进行了相反次序复测，全部记录为结构合法，包含加载预热的真实token另行留存。输出长度可能不同，执行时间和结构校验不证明建议质量或预测能力。

实际拟合与Qwen请求并发的训练活跃阶段吞吐：8/4为9.76，4/12为8.81，6/12为7.59，8/12为7.18拟合/秒。训练8、Qwen4相对训练8、Qwen12提高约36%的活跃训练吞吐；而空闲推理12更快。因此采用固定训练8、Qwen空闲12/计算队列待执行或运行时4，而不是固定某一个推理线程数。整个并发块的耗时另列，不混为活跃训练吞吐。

数值库环境与基准保持单线程BLAS/OMP初值，Torch显式设训练线程。为避免重用不同BLAS执行条件的旧分数，注册新数值身份，不做旧数值身份兼容映射。当前网络配方与原验证门槛没有放宽。
