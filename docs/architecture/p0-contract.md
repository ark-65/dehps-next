# P0/P1 冻结契约

## 本轮目标与非目标

Goal：`P1_RED_BLUE_CONTINUOUS_LEARNING`。
交付可运行的单机训练和预测反馈流程，真实训练红球与蓝球网络，保留数据、模型、预测、评价和消费链，
自动触发下一轮。用户于2026-10-29授权开始开发并允许只读沿用旧库开奖历史。

不交付或宣称：数学研究智能体、分支自我进化、Optuna搜索、全量P3回收、72小时/7天持续验收、
正式报告/邮件接管、蓝球50%效果达标。完整v1.1仍是后续目标，不因P1完成而删除其中要求。

## 数据与时间

- 只读来源：旧库`ssq_history`开奖事实；官方福彩最近100期用于交叉验证和后续新结果同步。
- 旧库不做DDL、DML、清理或维护，不复制凭据，不挂载旧代码/产物。
- Next采用独立数据库与受控文件目录；缺失/非法/冲突标签拒绝导入。
- 每个快照锁定目标期、截止时点、输入期次、来源与摘要；标签必须晚于其输入窗口。
- REPLAY：允许使用历史日期可用性，所有历史成绩始终标为回顾性时序回放。
- FORWARD：输入还必须在真实截止时点前被Next观察到；预测必须真实封存于登记截止前、目标标签未知时。
- 官方只给日期时，可用时间保守记为该日23:59:59+08:00，不能冒充真实秒级发布时间。

## 模型与评价

默认过去16期，每期33维红球指示+16维蓝球指示，128维隐藏层，红33输出与蓝16输出，共106,801参数。
红球BCE、蓝球交叉熵；Adam，CPU，默认内部2线程，每轮20epoch；固定种子与确定性计算。
父模型与优化器可在配方相同且时间顺序合法时继承。实际训练权重摘要必须变化。

每期固定100个合法去重六红组合，加唯一蓝球Top1。红球评分用边际log-odds的固定基数排序，
不把它称为联合概率。保留同历史频率基线和固定种子的随机100注对照。

评价只在封存后进行，按期计数。保存蓝Top1、蓝概率损失、红球Brier与Top100匹配分布及对照。
P1近期/随机历史只作为已产生时序回放记录的描述性核查，抽样清单与种子可查看；
完整父子同清单复核、保护holdout与统计晋升属于P2，不能用P1描述性抽样替代权威候选比较。
蓝球50%始终显示未建立证据，不根据短回放改变标签。

## 任务链与完成事实

`Data snapshot -> TRAIN -> Model/Consumption -> SEAL -> Prediction -> EVALUATE -> Next cycle`。

TRAIN就绪：过去数据足够、配方固定、空间允许。
SEAL就绪：模型和数据集可读取且校验正确；FORWARD还要求未过期、结果未知。
EVALUATE就绪：预测已经封存、标签可用。
下一轮：前一轮评价提交，下一期或新数据满足条件；没有就绪任务则如实等待。

数据库事务共同提交模型/消费/任务完成，或预测/任务完成，或评价/任务完成。
执行状态以PostgreSQL为权威，不从日志推断成功；任务领取采用短事务与SKIP LOCKED，训练期间不持长事务。
过期租约以独立attempt令牌隔离，重复完成不可接受。检查点覆盖随机状态、优化器、输入摘要和训练游标。
