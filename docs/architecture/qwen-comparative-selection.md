# Comparative selection and explicit recovery

The former v3 selector accepted legal IDs and citations without establishing that
Qwen used feedback. The v4 controller requires assessments of every alternative,
then complete within-group rankings, then the selected ranking head. Recipe IDs
are opaque hashes. Presentation order and ID assignment have separate seeds;
candidate IDs are free strings in the decoder schema, rather than ordered enums.
Only evidence keys use an enum. Exact observed recipes must cite their own record
and reproduce their recorded utility; unobserved utilities remain null. Numerical
results, changes and promotion decisions remain program-owned facts.

Immutable audits retain the candidate identities, display order, ID mapping,
request schema, response, selected positions, receipts and rejected attempts.
Failure receipts remain available even when decoding, a later lease fence or GPU
verification rejects the output. No invalid response silently selects the first ID.

A profile is inactive until its frozen mechanism study passes. Activation recomputes
the gates from all144 immutable request records:12 real, uniquely ranked three-choice
cases, three independent presentation/identifier variants, two seeds and two arms.
Require feedback accuracy90%, recipe stability80%, first-position share at most50%
and feedback accuracy advantage at least20 percentage points. The profile pins the
official model digest, thinking mode, sampling and context settings. Actual token
receipts and full GPU residency are required. A reasoning pass is not predictive
evidence. The first passing configuration in the approved model/mode order wins;
subsequent fitting outcomes cannot choose the reasoning model.

Until a profile passes, and after a malformed response or diagnosed position bias,
the existing value network selects among the novel alternatives. Its128-step updates
use persisted, comparable cross-round paired outcomes. Selection source and failure
reason are explicit. A genuinely empty feedback cohort instead uses reproducible
cold-start exploration, never a claim of a trained value model. Inference outages
back off while fitting continues; semantic failures remain quarantined pending a
new validation. A90/100 first-position watchdog also quarantines live regressions.

The read-only status API exposes profile state, actual selection sources, position
statistics and immutable study results. Value selection does not establish that
Qwen improved, nor that feedback beats no feedback. The separately frozen24-pool
comparison runs only after mechanism acceptance, locks all48 arm choices before
evaluating144 recipes on14,400 historical origins, and keeps its100 shared draw
labels distinct from forward evidence. Its primary is the existing paired reward;
promotion fraction is secondary. A positive difference and one-sided exact sign-flip
p<=.05 are both required to claim a development comparison benefit. Invalid arms
preclude that claim; the fixed sample is never extended to seek significance.

Promotion, qualification, parent retention, mail policy, numerical fitting identity
and CPU/GPU allocations are unchanged. Campaigns freeze the active profile ID;
activation and campaign creation share the controller lock. Switch releases only
at a completed batch boundary. No unit tests or CI are added.
