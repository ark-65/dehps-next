# 持续历史回归与最后一分钟封存

这是 v1.1 的执行补充，2026-10-29 用户纠正提前封存后的生效政策。原 v1.1 原文保留；本文件更新 P2/P3 的研究节奏、发布模型选择和邮件封存时机。旧 DEHPS 不在操作范围内。

## 两个独立时钟

研究以任务完成为时钟，全天在合法历史边界进行训练、分支比较和恢复，不等待未来开奖。官方同步带来新数据后，更新研究快照并重新验证。每轮最多8节点、活动间隔30秒、每日最多12轮；这些是防空转上限，不是一定要填满的工作量。日总预算仍为7200容量秒和24次本地推理调用，资源压力及写入保护继续生效，重启不清零。

本地模型在根节点和后续每获得三条观测后进行有限推理。其余步骤复用已有数学假设，由实际训练的225参数方向价值网络在尚未尝试的因果配方中选择下一方向。调用预算不足不阻止小网络训练与历史验证，不把这个路径伪装成新的大模型推理。有限配方包括 Fourier/ridge/Newton、窗口8/16/32、隐藏层64/128、训练12/28轮、学习率0.0005/0.002/0.005、L2 0.001/0.01、训练历史128/256。按真实开发反馈重训方向评分；不是无限算法发现或LLM权重自训练。

同快照同代码已经尝试的配方不重复。三个问题族结束一轮后仍可继续下一轮的新配方；只有配方空间、当日活动数或总资源预算耗尽才等待。跨活动根节点可能复用历史评分缓存，但必须明确区分复用量和本次实际梯度步数。

邮件以日历为时钟。上海时区开奖日16:59（含）至17:00（不含）才可生成当期正式预测；17:00发送。白天 `report-prepare` 只登记日程和检查候选，无法提前封存。数据库触发器重复检查真实系统时钟、开奖日、截止时间和未知结果条件，客户端提供伪造封存时间也不能绕过。错过窗口发送无合格封存的状态报告，不在17:00后补造预测。

## 固定的历史比较

每个快照预先冻结最近100期、其中最后10期、按十个时间层随机抽样的200个历史起点，以及40个预登记备用起点。固定种子1729，重叠只计一次。3520期历史对应290个主起点及40个不重叠备用起点。

每个起点仅把目标之前、当时已可用的历史前缀交给拟合器，目标标签只交给评分器。相同起点的父子模型从共同种子重新拟合；禁止把今天的模型放回过去预测。逐起点保留期号、训练截至期、概率、参数更新证明和指标。发布守卫从概率和不可变开奖数据重算损失、红球Brier及唯一蓝球Top1，核对协议摘要和前缀边界。

配对区块bootstrap保留1000次、块长5、蓝球损失差容忍0.02、红球Brier容忍0.01。明确退步后立即剪枝，不再支付40起点复核费用；不确定时追加一次有限复核，仍不确定则恢复父节点。可接受的新父节点补齐备用评分以支持后续同清单比较。最近10期单列保护，不因单独命中一两次就宣布改进。接受后从该节点继续子方向；改变窗口、结构或特征族不兼容时，从同一合法数据边界重训，不强行载入旧形状。

研究恢复锚点保存父权重、优化器、随机状态和数学状态。正式发布锚点另按历史回归的相同独立训练流程拟合，避免“历史从头训练、正式用额外继承训练”的协议差异。FFT、ridge残差系数和Newton温度在正式推理时完整保留。当前发布推理不在最后一分钟重新训练。

## 发布守卫和证据边界

只能选择当前代码、最新数据快照的已接受节点。父节点比较须为 ACCEPT_BASELINE 或 ACCEPT_IMPROVEMENT；最近100期及随机历史的蓝球平均损失相对均匀基线不得恶化超过0.02，最近10期容忍0.10；三个窗口的红球Brier相对均匀红球边际参考不得恶化超过0.01。容忍度事前固定，不为通过某个候选临时改变。

这是开发发布的退步保护，不是“已证明优于随机”。邮件明确标为研究性推荐，并显示近100、近10、随机历史的命中与真实前向累计。50%业务最低目标不变；反复搜索使用过的历史不能作为独立证据或稳定50%能力声明。正式能力仍需未受搜索污染的预登记评价和真实前向观察。

正式封存时创建新的FORWARD数据版本，检查封存时真实已观测且可用的记录与发布锚点输入逐行相同，绑定模型、配方、发布代码、研究节点、完整协议和压缩评分。核心预测事实及评分证据受GC保护，普通失败分支仍按有界保留政策回收。

原2026124期14:28封存及已发验收邮件保持原样；追加排除账本，不能计入新的17:00正式推荐统计。正式复盘只评价正式PRE报告关联的预测；未封存的指定期次记录覆盖缺口并按业务口径计为未命中，不通过跳过失败期提高命中率。邮件队列沿用持久去重和SMTP不确定状态保护。

## 运行

```bash
docker compose -f compose.yaml -f compose.inference.yaml run --rm worker init
docker compose -f compose.yaml -f compose.inference.yaml run --rm worker program-disable --name autonomous-p3
docker compose -f compose.yaml -f compose.inference.yaml run --rm worker program-enable \
  --name autonomous-v2 --interval 30 --max-daily 12 --max-nodes 8 --planner local --seed-program autonomous-p3
docker compose -f compose.yaml -f compose.inference.yaml up -d
```

旧活动必须完成或明确终止后再发布；兼容升级按既有采用审计执行。新的程序种子可取已登记旧程序的选中配方，必须重新完成新协议验证，不能继承旧代码下的通过结论。

主机代理遇到构建替换标签后Docker旧镜像配置ID暂不可解析时，使用该Next容器的完整rootfs尺寸作保守上界；无法取得上界仍阻塞。此修复不忽略资源核算，也不执行全局镜像清理。
