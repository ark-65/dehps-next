# 开奖日晚间准备与最终邮件

2026-10-29 用户纠正：17:00是最晚开始准备的时间，20:00前要完成并发送。这个政策替代旧的16:59–17:00封存及17:00最终报告时钟；研究协议、模型门槛和持续研究节奏保持不变。

上海时区开奖日：

| 时间 | 行为 |
|---|---|
| 17:00 | 登记期次日程，进入最终准备；反复核对最新数据快照、近100期/近10期/分层随机历史验证及候选资格。不在此时判定覆盖缺口 |
| 17:00–18:50 | 持续研究、退步回退和换方向，准备发布候选及已验证发布锚点 |
| 18:50（含）–19:00（不含） | 从当前代码和最新数据边界的合格候选正式封存；尚无候选则继续等待，不能降低门槛 |
| 19:00 | 生成并投递唯一最终报告。有封存则附号码与证据；无封存则如实发送最终研究状态，并登记一次覆盖缺口 |
| 19:30 | 内部发送截止；未发送的开奖前报告转EXPIRED，不在截止后补发过时推荐。保留失败/未知SMTP状态 |
| 官方结果到达后 | 复盘最终有效预测或一次覆盖缺口，不把提前验收或17:00旧状态混入 |

19:30是为20:00前购买留出时间的保守内部邮件截止，不是对官方停售时间的声明。19:00服务检查和SMTP接受有正常调度延迟；SMTP接受不等于用户已经阅读或邮箱已送达。服务离线、过期日历、无合格候选时如实暴露失败，不倒填封存或发送时间。研究不因封存或报告完成而停下等待开奖。

## 当天旧17:00状态的追加修正

2026124期的17:00状态邮件和MISSED事实均保持不可变。迁移009只在真实服务器时钟尚早于当日19:00、原决策确为旧17:00无预测、没有封存周期且结果未知时，追加forecast_schedule_reopenings记录。已开奖、已有正式预测或已到新截止时都不能重开。

新决定进入不可变forecast_final_selections。effective_forecast_selections优先使用最终决定；重开的旧17:00 MISSED不参与新截止之前的缺口结算，也不会阻挡晚间封存。修正不是删除失败记录：旧邮件和决定、重开原因及最终新决定全部可追踪。

新邮件使用独立PRE_FINAL去重，正文明确“日程修正”和“最终报告”。旧PRE保持不变，不重发。后续开奖前报告继续每期一次。正式复盘和累计统计使用有效决定，每期仅统计一次；GC同时保护新旧正式证据。

应用、数据库触发器同时检查18:50–19:00真实封存时钟。17:00准备命令及force不能提前封存或提前标缺失；19:00后不能补造预测。封存和最终判缺使用同一个数据库事务锁，避免临界点误报缺失。所有用户可见时刻使用Asia/Shanghai。

当前8/4/1核、本机token仅统计、无每日容量秒或调用次数限额继续有效。旧DEHPS未纳入改动。
